# dart-vision

カメラ1台と PC だけで、壁の的に刺さったダーツの位置を OpenCV で見つけて判定する自作プロジェクトです。
今は「**的の真ん中の丸に入ったかどうか(IN / OUT)**」を判定できます。

## 必要なもの

- Python 3
- OpenCV: `python -m pip install opencv-python`
- Web カメラ(Logicool C270n で動作確認)
- 的のまわりを照らすライト(LED テープを的のまわりに貼ると影が短くなり、判定が安定します)

## 使い方

```
python dart_detect.py
```

1. 映像の上で、的のまわりをマウスでドラッグして囲み、Enter
2. target ウィンドウで、真ん中の丸のふちを 5〜8 か所クリック(黄色い輪ができる)
3. ダーツが刺さっていない状態で `b`
4. ダーツを刺すと、先端に緑の丸が付き、IN! / OUT が表示される

| キー | すること |
|---|---|
| `b` | 刺さる前の画像(基準)を保存 |
| `m` | 真ん中の丸をやり直す |
| `u` / `j` | 「変化あり」とみなす差を大きく / 小さく |
| `c` | 細い線・小さい点を消す処理のオン / オフ |
| `r` | 範囲を選び直す |
| `q` | 終了 |

## 判定のしくみ

1. 刺さる前と今の画像を色ごとに比べ、変わった場所を白くする(差分)
2. 細い線や小さな点を消す(オープニング。マットのずれやダーツの揺れ対策)
3. いちばん大きい白いかたまりをダーツとみなす
4. かたまりの重心からいちばん遠い点を先端とする
5. クリックした点に合うだ円(`fitEllipse`)の中に先端があれば IN

## ファイル

| ファイル | 内容 |
|---|---|
| `dart_detect.py` | メインのプログラム(ダーツ検出・先端・IN/OUT 判定) |
| `camera_setup.py` | カメラを開いて露出などを固定する共通部品 |
| `camera_test.py` | カメラ映像を表示するだけのテスト |
| `camera_settings.py` | カメラの設定値を確認する |
| `camera_fixed.py` | 露出を手動で調整しながら映像を見る |
| `dart_diff.py` | 差分だけを表示する練習用プログラム |
| `CLAUDE.md` | プロジェクトのメモと進み具合 |
